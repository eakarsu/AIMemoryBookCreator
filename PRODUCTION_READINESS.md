Only opaque storage references and digests are retained; retention and document scope are explicit.

Apply `backend/migrations/001_governed_ingestion.sql` via the approved deployment migrator, never startup. Repository, object storage, parser queue, search index, print vendor, and notification connectors remain receipt-only declarations until credentials, deletion/replay contracts, and acceptance tests exist. Generated narrative, vision, video, and print/provider routes are quarantined in production.

The deterministic gate checks recall, faithfulness, citation resolution, freshness, and injection scan status. Weak results abstain; no answer is generated by the governed layer. Versioned representative datasets, rights/consent review, citation resolution, encryption, deletion propagation, and print proofs remain required external gates.

Configure from `.env.example` with secrets management and keep demo/bootstrap/provider flags false. Run `node --test backend/governance/workflow.test.cjs` and `bash -n start.sh`. Startup performs no installation, migration, seeding, database creation, or port reclamation.
